# Image Prompts - Stickman Style
# بروم صور كل مشهد بأسلوب الشخصية العصا

## الأسلوب العام لكل الصور:
```
Style: Minimalist stickman illustration, flat vector art, thick black outlines on pure white background,
educational YouTube style, high contrast, expressive stick figure character,
NO text inside image, NO watermark, NO logo, 16:9 landscape ratio, clean simple composition.
```
