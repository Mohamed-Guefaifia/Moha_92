# قالب إنتاج الفيديو — قناة الإسلام والنفس

## كيفية الاستخدام

لإنشاء فيديو جديد، اكتب في Claude Code:
```
/arabic-video [الموضوع]
```

### أمثلة:
- `/arabic-video الغضب وكيف يدمر حياتك`
- `/arabic-video الحسد والعين في الإسلام`
- `/arabic-video التوبة النصوح — كيف تبدأ من جديد`
- `/arabic-video الصبر على البلاء`
- `/arabic-video الوسواس القهري والإسلام`

## هيكل المشروع
```
ProjectN/
├── Research/       ← آيات + أحاديث + علم نفسي
├── Script/         ← السكريبت العربي الكامل
├── Storyboard/     ← تقسيم المشاهد
├── Animation/      ← ملف HTML متحرك جاهز للتسجيل
├── Assets/         ← التعليق الصوتي (vidIQ)
├── Thumbnail/      ← الصور المصغرة
└── Metadata/       ← العناوين + الوصف + الوسوم
```
